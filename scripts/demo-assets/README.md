# Demo pictures

These bundled JPEGs keep seed runs independent of public image services.
The seed uploads them to configured object storage and persists file IDs, not URLs.
They are illustrative pictures for fictional Members and campus projects.

Quest pictures: Pexels, under the [Pexels license](https://www.pexels.com/license/).
The exact source for each Quest is `imageSource` in `../demo-quests.ts`.
Portfolio pictures reuse the corresponding Quest picture.

Avatars: [Random User Generator](https://randomuser.me/), downloaded from
`https://randomuser.me/api/portraits/men/10.jpg`, women/11, men/12, women/13,
men/14, women/15, men/16, women/17, men/18, and women/19, in Member order.
Names and all academic and contact data are fictional; portraits are sample imagery.
