SINGLE + CANDIDATE Application & Selection Sequence

Visualizing the competitive application lifecycle: prospective Candidates submit applications while QUEST_OPEN, the Hirer evaluates candidates, and selecting one Candidate atomically assigns them while rejecting all competing applicants in a single transaction.

BRUNO FOLDERS

1. Applying

  • Quest-Candidates / Apply as Candidate: Prospective workers submit applications.
  • Quest-Candidates / Withdraw Application: Allows a candidate to cancel before selection.

ATOMIC CONTRACT

2. Selection Guarantee

  • Quest-Candidates / Select Candidate: Hirer picks the winner.
  • Single Transaction: Winner becomes ASSIGNMENT_ACTIVE and all other applicants are rejected atomically.

BRUNO FOLDERS

3. Post-Selection

  • Work-Chat / Send Message: Communication opens exclusively for the selected pair.
  • Quest-Proof / Submit Proof: Selected worker submits deliverable for review.
