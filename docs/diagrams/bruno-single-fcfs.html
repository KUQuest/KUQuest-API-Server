SINGLE + FIRST_COME_FIRST_SERVED Lifecycle Sequence

Visualizing the direct join pathway: a single Worker joins directly on an open Quest, enters active assignment immediately without candidate review, completes work, and triggers automatic ledger release upon approval.

BRUNO FOLDERS

1. Quests & Join

  • Quests / Create Quest Draft: Mode = FIRST_COME_FIRST_SERVED, Participation = SINGLE.
  • Quests / Publish Quest: Locks Escrow immediately.
  • Quests / Join Quest (Worker): 1st eligible click wins.

BRUNO FOLDERS

2. Chat & Proof

  • Work-Chat / Send Message: Real-time coordination.
  • Quest-Proof / Create Proof Submission Draft: Prepares work description.
  • Quest-Proof / Submit Proof to Hirer: Moves Quest to QUEST_SUBMITTED.

BRUNO FOLDERS

3. Review & Payout

  • Quest-Proof / Hirer Approve Proof: Moves to QUEST_COMPLETED.
  • Settlement: Reward satang transferred from Escrow into Worker's earningsBalanceSatang.
  • Quest-Review / Create Rating Review: Post-completion 5-star rating.
