Bruno Collection Architecture Map

Full Test Suite Flow Across All Bruno Folders

End-to-end integration path connecting every test folder in the Bruno workspace: from session authentication and double-entry Top-up clearing, through the 4 Quest combos, Work Chat, and atomic ledger settlement.

PREPARATION

1. Session & Top-up

  • Auth: Run Staging Test Student Sign In once to capture the session cookie.
  • Quote & Top-up: Obtain PromptPay QR, simulate payment, and funds post to spendingBalanceSatang via double-entry subledger.

ROSTERING

2. Four Selection Pathways

  • Q1 (Single FCFS): Direct join assigns slot immediately.
  • Q2 (Single Candidate): Candidates apply; Hirer selects winner.
  • Q3 (Group FCFS): Slot-by-slot join; underfilled protocol if short at start.
  • Q4 (Candidate Team): Team Leader forms squad via 24h Join Code.

EXECUTION & SETTLEMENT

3. Work, Chat & Money Release

  • Work Chat: Real-time messaging opens automatically once assigned.
  • Proof: Worker creates draft, adds attachments, and submits.
  • Escrow Settlement: Hirer approval releases funds from Escrow into Worker's EARNINGS.
