GROUP + FCFS & Underfilled Consensus Sequence

Visualizing group slot-by-slot joins and the 10-minute underfilled consensus gate: when startTime arrives with fewer workers than published headcount, the Hirer decides whether to proceed or cancel, followed by mandatory unanimous consent from joined workers.

BRUNO FOLDERS

1. Slot-by-Slot Join

  • Quests / Create Quest Draft: Headcount = 3, Mode = FCFS, Participation = GROUP.
  • Quests / Join Quest: Workers claim slots individually.

CONSENSUS GATE

2. 10m Hirer Gate

  • Quest-Underfilled / Get Status: Inspects current joined headcount.
  • Quest-Underfilled / Hirer Decide: Hirer has 10 minutes to choose PROCEED or CANCEL.

UNANIMOUS CONSENT

3. Worker Consent

  • Quest-Underfilled / Worker Consent: Each joined worker accepts adjusted rewards.
  • If all accept, Quest advances to QUEST_ASSIGNED.
