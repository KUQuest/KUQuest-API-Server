problem
Five callers each remember the same four steps — check the State, write the State, settle or release Quest Escrow, move Work Conversation membership — which is why settlement and the worker are the two highest-churn implementation files in the repo.
solution
A Quest lifecycle module whose interface accepts a requested transition and performs all four steps atomically; callers name the transition, not the steps.
  • locality: transitions in one module
  • leverage: five callers, one verb
  • partial transitions become impossible
  • tests drive transitions, not rows
ADR-0019 requires atomic Quest completion; today atomicity is a convention each caller follows. Reinforces the ADR, no conflict.
