# Superseded: Use one Proof Review Window for every Quest

> **Superseded for Quest lifecycle behavior.** The accepted product rule is
> [`docs/quest/work-chat-system-target.md` §Resolved Quest lifecycle](../quest/work-chat-system-target.md#resolved-quest-lifecycle).

The one-hour review window described by this ADR is current-server behavior.
The accepted rulebook gives the Hirer 24 hours after Proof Submission before the
Server records `PROOF_APPROVED`.
