# Retain and correct financial records

Ledger, payment, and provider-event history is never hard-deleted, and sealed postings are never edited. Financial mistakes are corrected by linked reversing or replacement transactions so the audit trail remains explainable; mutable resources such as Payout Destinations are retired rather than erased. Student deletion is blocked while financial references exist, with a future account-deletion workflow responsible for anonymizing personal data while retaining the minimum pseudonymous financial history.
