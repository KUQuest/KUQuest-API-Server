## 2. Design Specificity Assessment
- **Bespeak vs Generic**: Highly bespoke. Tailored specifically for state machines, campus scenarios, and double-entry ledger Satang math.
- **Key Domain Innovations**:
  1. **Side-by-Side In-Tandem Sequence Diagram Stage**: Pinned sticky diagram column allows simultaneous verification of step execution and network message sequence without vertical scroll disconnections.
  2. **Dual-Mode Tracing Workbench (2-Pane)**: 120-item sticky sidebar navigator with instant keyboard shortcuts (`J`/`K`/`W`/`/`) and dedicated inspector pane.
  3. **Double-Entry Satang T-Account Validation**: Explicit mathematical balance badges showing credit/debit matching across Hirer, Worker, Platform, and Escrow accounts.
  4. **Relatable Real-World Campus Stories**: Narrative framing grounding abstract technical test cases in concrete KU student interactions.
  5. **Ubiquitous Language Glossary & Tooltips**: Instant hover definitions citing formal Rulebook sections for all domain states and codes.

## 3. Nielsen's 10 Usability Heuristics Scoring
1. **Visibility of System Status** [4/4]: Clear status badges, active scenario highlights, real-time filtered counts.
2. **Match Between System & Real World** [4/4]: Natural Thai language narratives matching KU student campus culture and domain contracts.
3. **User Control & Freedom** [3.5/4]: Dual view switcher, keyboard shortcuts, quick filter reset, direct URL anchors.
4. **Consistency & Standards** [4/4]: Standardized 120-card anatomy, uniform semantic color taxonomy (Green/Red/Amber/Purple).
5. **Error Prevention** [3.5/4]: Idempotent multi-facet filter synchronization, non-jumping URL hash replacement.
6. **Recognition Rather Than Recall** [4/4]: Ubiquitous Language hover tooltips, active tags strip, quick-jump matrix.
7. **Flexibility & Efficiency of Use** [4/4]: Power-user keyboard controls (<kbd>J</kbd>/<kbd>K</kbd>/<kbd>/</kbd>/<kbd>W</kbd>), 1-click Test Spec copy.

9. **Help Users Recognize, Diagnose & Recover From Errors** [3.5/4]: Dynamic active filter tags with 1-click removal, reset all fallback.
10. **Help & Documentation** [4/4]: Interactive searchable glossary modal, explicit Rulebook and ADR citations on every card.
